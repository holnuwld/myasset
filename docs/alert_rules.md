# 알림 및 자산 배분 모니터링 규칙 명세 (`alert_rules.md`)

> 이 문서는 만기 알림, 유휴 자금(놀고 있는 돈) 알림, 카테고리별 자산 배분 모니터링의 판정 로직을 정의합니다.

## 1. 만기 자산 알림 규칙 (Maturity Alert)
- **대상**: `maturity_date`가 입력된 모든 자산
- **기준일**: 실행 시점의 한국 시간(`Asia/Seoul`) 오늘 날짜 (`today`)
- **남은 일수 계산**: `days_left = (maturity_date - today).days`
- **알림 발화 단계**:
  - `days_left < 0`: **[만기 경과]** 만기일이 지났으나 해지/재예치 처리되지 않은 자산 (즉시 확인 필요)
  - `days_left == 0`: **[만기 당일]** 오늘 만기 도래
  - `0 < days_left <= 7`: **[만기 임박 (D-7 이내)]** 일주일 내 만기 도래
  - `7 < days_left <= 30`: **[만기 예정 (D-30 이내)]** 한 달 내 만기 도래 사전 예고

## 2. 무이율/저이율 계좌 유휴 자금 알림 규칙 (Idle Cash Alert)
- **목적**: 이율이 거의 없는 일반 수시입출금 계좌나 증권 예수금에 방치된 현금을 탐지하여 파킹통장/CMA/MMF 이동을 권고
- **대상 카테고리**: `category == "현금성"` 또는 `sub_type in ["수시입출금", "일반예금", "예수금"]`
- **탐지 조건 (기본값, 설정 파일에서 변경 가능)**:
  1. `interest_rate <= 0.5` (연이율 $0.5\%$ 이하 — 무이율 $0.0\%$ 포함)
  2. `valuation_krw >= 1,000,000` (최소 유휴 자금 임계치: $100$만 원 이상)
- **출력 정보**:
  - 해당 계좌명, 현재 잔액, 현재 이율($\%$)
  - 기회비용 추정치: 파킹통장 기준금리(예: 연 $3.0\%$) 적용 시 **연간 추가 수취 가능 이자액** (`잔액 * (0.03 - 현재이율/100)`) 함께 안내

## 3. 자산별 카테고리화 및 배분 비율 모니터링 규칙 (Asset Allocation)
- **집계 기준**: 전체 자산의 `valuation_krw` 총합 대비 각 `category`(`주식`, `채권`, `예적금`, `부동산`, `현금성`, `연금`, `기타`)의 합계 비중($\%$) 산출
- **계산식**:
  $$\text{카테고리 비중(\%)} = \frac{\sum \text{해당 카테고리 평가금액}}{\sum \text{전체 자산 평가금액}} \times 100$$
- **리밸런싱 모니터링**:
  - 목표 비중(`target_ratio`)이 설정된 경우 `편차(%p) = 현재 비중 - 목표 비중`을 계산
  - 절대 편차가 $\pm 5.0\%\text{p}$ 이상 벌어지면 **[리밸런싱 권고]** 표시
